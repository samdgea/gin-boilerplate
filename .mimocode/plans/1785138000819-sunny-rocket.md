# Plan - Register Endpoint Implementation

## Proposed Changes

### controllers/authControllers.go
- Add a new `Register` controller function:
  - Expects `username`, `first_name`, `last_name`, `password`, `verify_password` in request body.
  - Returns `utils.ThrowError` with HTTP Status Bad Request if parameters are missing or invalid.
  - Returns `utils.ThrowError` with HTTP Status Bad Request if `password != verify_password`.
  - Verifies username uniqueness.
  - Hashes the password with `bcrypt.GenerateFromPassword(..., bcrypt.DefaultCost)`.
  - Creates a new `UserModel` instance with `IsActive: true` and saves it via `db.DB.Create`.
  - Responds with JSON success response.

### routes/auth.go
- Register `POST /register` mapping to `controllers.Register` before middlewares.

## Verification
- Start the server using `go run main.go`.
- Test successful registration using Curl or Postman payload.
- Test missing fields, password mismatches, and duplicate usernames.
